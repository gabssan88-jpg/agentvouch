How Agent ID is used

  • Access control: the contract calls balanceOf(address) on the Agent ID registry (0x60b9262456de011f7d15a54cdd8c48baaa8b022f) before every registration, profile update, reactivation and vouch. No Agent ID, no write access.
  • Sybil resistance: Agent ID is non-transferable and capped at one per user, so reputation cannot be farmed with throwaway wallets.
  • Reputation graph: vouches are public, one per pair, and revocable — a transparent trust signal other users and apps can read directly on-chain.

Safety & permissions

  • The AgentVouch contract has no owner and no admin functions: it cannot mint, pause, freeze, change fees, or withdraw funds. It never takes custody of assets and is not payable.
  • Connect only through your wallet's standard injected provider on this page. This site never asks you to scan a QR code or enter a pairing code to sign in, and never asks for a seed phrase, private key, or API secret.
  • Every action is a transaction you review and confirm in your own wallet. Nothing is auto-signed and nothing is transferred on your behalf.
  • AgentVouch is a reputation tool. It does not promise any return, yield, or reward.
